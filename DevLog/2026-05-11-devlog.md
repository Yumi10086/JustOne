# JustOne 项目开发日志

## 2026-05-11

### 项目概述

**项目目标**：适配 Python 3.14 的子域名收集工具，参考 OneForAll

**技术栈**：
- CLI: Typer
- 进度条: tqdm
- 配置: Pydantic + .env
- 日志: loguru
- HTTP: requests + aiohttp (异步)
- DNS: dnspython

## 使用示例

```bash
# 基本收集
python justone.py main bilibili.com

# 仅使用搜索引擎（禁用证书、数据集、爆破）
python justone.py main bilibili.com --no-brute --no-cert --no-dataset

# 导出结果
python justone.py main bilibili.com -o results.csv -f csv

# 仅爆破
python justone.py brute bilibili.com -c 1000

# 检查存活
python justone.py check bilibili.com --dns

# 批量检查
python justone.py check -i results.txt -f txt
```
