# JustOne 项目开发日志

## 2026-05-11

### 项目概述

**项目目标**：适配 Python 3.14 的子域名收集工具，参考 OneForAll

**技术栈**：
- CLI: Typer
- 进度条: tqdm
- 配置: Pydantic + .env
- 日志: loguru
- HTTP: requests + aiohttp (异步)
- DNS: dnspython

### 2. 修复 get_logger 函数 ✅

**问题**：modules 中调用 `utils.get_logger()` 但该函数不存在

**解决方案**：在 `common/utils.py` 添加 `get_logger()` 函数

```python
def get_logger():
    """获取日志记录器"""
    from config.logging import logger
    return logger
```

### 3. 完善 collect.py 模块集成 ✅

**新增功能**：
- `_init_modules()` 自动加载各类型模块
- `_init_search_modules()` - 加载 BaiduSearch, BingSearch
- `_init_certificate_modules()` - 加载 Crtsh
- `_init_dataset_modules()` - 加载 LeakIX
- `_run_module()` - 统一执行单个模块，记录实际耗时
- `add_module()` - 添加自定义模块
- `get_summary()` - 获取收集摘要

### 4. 完善子模块逻辑 ✅

**baidu.py, bing.py**：
- 添加 `run()` 模块入口函数
- 添加延时避免请求过快
- 优化日志输出

**crtsh.py, leakix.py**：
- 添加 `run()` 模块入口函数
- 优化错误处理

### 5. justone.py Typer CLI 入口 ✅

**命令**：

### 6. Bug 修复 ✅

**问题1**：timeout 参数冲突

**解决**：移除 crtsh.py 和 leakix.py 中的 timeout 参数

**问题2**：耗时统计错误
**解决**：

## 使用示例

```bash
# 基本收集
python justone.py main bilibili.com

# 仅使用搜索引擎（禁用证书、数据集）
python justone.py main bilibili.com --no-brute --no-cert --no-dataset

# 导出结果
python justone.py main bilibili.com -o results.csv -f csv

# 仅爆破
python justone.py brute bilibili.com -c 1000

# 检查存活
python justone.py check bilibili.com --dns
```
